# 样本冻结与研究证据规范

本规范用于 Bitget 策略研究阶段，目标是避免反复触碰同一批样本导致过拟合。它不生成 profile，不进入 live，不触发任何交易所私有接口。

## 冻结样本 manifest

先准备训练集、验证集和最终样本外集，然后生成 manifest：

```powershell
kxian-bot --no-dotenv freeze-sample-manifest `
  --exchange bitget `
  --symbol BTCUSDT `
  --interval 4h `
  --train-files artifacts/samples/train/*.csv `
  --validation-files artifacts/samples/validation/*.csv `
  --final-oos-files artifacts/samples/final-oos/*.csv `
  --output-file artifacts/样本清单.json
```

manifest 会记录：

- `schema=kxian.sample_manifest.v1`
- manifest id
- scope
- 每个样本的 role
- 文件 SHA256
- K 线数量
- 起止时间
- `touch_count=0`
- `final_oos_touch_policy=do_not_use_for_screening_until_candidate_locked`

## 生成策略研究证据

先运行只读筛选命令并保存 JSON 结果，再绑定 manifest 生成研究证据：

```powershell
kxian-bot --no-dotenv strategy-research-evidence `
  --manifest artifacts/样本清单.json `
  --hypothesis-id H-BITGET-001 `
  --hypothesis "BTCUSDT 4h 回踩回收在趋势过滤后降低噪声" `
  --strategy volatility_regime_pullback_reclaim `
  --command "kxian-bot --no-dotenv screen-samples ..." `
  --result-file artifacts/screen-result.json `
  --max-combinations 500 `
  --skip-combinations 0 `
  --evidence-out artifacts/研究证据-H-BITGET-001.json
```

研究证据会记录：

- `schema=kxian.strategy_research.evidence.v1`
- hypothesis id
- 策略名
- manifest id
- manifest 文件 SHA256
- 筛选结果文件 SHA256
- 参数预算
- 失败矩阵
- final OOS 是否被筛选命令触碰
- `will_submit_orders=false`
- `writes_strategy_profile=false`
- `live_ready=false`

## 硬规则

- `final_oos` 不得出现在 `screen-samples` 输入中。
- `screen-samples` 只允许用于预筛，不能直接作为 profile 或 live readiness 证据。
- 只有训练集与验证集筛出候选后，才能锁定候选，再触碰 final OOS 一次。
- research-only 策略不得用于 `run-once`、`trade-loop`、profile 晋升或 Bitget live gray 批准。
- 不得降低 `strategy_gate`、`sample_validation_gate`、`stress_gate`、`walk_forward_gate` 换取通过。
