# 测试网闭环操作手册

本手册只覆盖 `Binance testnet / BTCUSDT / 4h` 闭环验收。目标是拿到测试网证据，并在 `launch-checklist --target testnet` 返回 `status=pass`、`phase=testnet_observed_ready_for_live_review` 后停止。

## 安全边界

- 只使用测试网凭证，禁止使用生产 API Key。
- 由操作者手动从 `.env.testnet.example` 复制并填写 `.env`，不要让工具生成、覆盖或提交 `.env`。
- `.env`、`data/`、`*.sqlite3` 已纳入 `.gitignore` 保护。
- 本阶段不执行 `promote-profile-to-live`，不启动 `live`，不改真实生产密钥。
- 保持 live 开关关闭：`KXIAN_ALLOW_LIVE=false`、`KXIAN_LIVE_DRY_RUN=true`、`KXIAN_ENABLE_LIVE_AUTOTRADE=false`、`KXIAN_LIVE_CONFIRMATION=`。

## 准备 .env

```powershell
Copy-Item .env.testnet.example .env
```

手动填写：

```dotenv
KXIAN_MODE=testnet
KXIAN_EXCHANGE=binance
KXIAN_SYMBOL=BTCUSDT
KXIAN_INTERVAL=4h
KXIAN_USE_TESTNET=true
KXIAN_MARKET_DATA_SOURCE=exchange
KXIAN_BINANCE_API_KEY=你的测试网 key
KXIAN_BINANCE_API_SECRET=你的测试网 secret
```

可先保持以下开关做凭证准备和只读网络排查：

```dotenv
KXIAN_ENABLE_TESTNET_AUTOTRADE=false
```

非下单观察前继续保持 `false`。进入 bounded `--execute-loop` 下单观察前，必须手动改为：

```dotenv
KXIAN_ENABLE_TESTNET_AUTOTRADE=true
```

这是测试网闭环硬门禁的一部分；不带 `--execute-loop` 的 `testnet-dry-run` 和 `testnet-observe` 仍不会提交订单，只有 bounded 下单观察步骤会尝试一轮受控测试网订单。

## 固定命令顺序

建议把脱敏证据包写到已忽略的 `artifacts/` 目录，例如 `--evidence-out artifacts/testnet-dry-run.json`。证据包只保留凭证 boolean，不包含 API key/secret 原文或片段。

```powershell
kxian-bot strategy-profile
kxian-bot testnet-setup-check
kxian-bot readiness
kxian-bot launch-checklist --target testnet
kxian-bot exchange-health --timeout-seconds 5
kxian-bot testnet-dry-run --evidence-out artifacts/testnet-dry-run.json
kxian-bot testnet-observe --cycles 6 --sleep-seconds 60 --evidence-out artifacts/testnet-observe.json
# 到这里确认非下单观察通过，再把 KXIAN_ENABLE_TESTNET_AUTOTRADE=true
kxian-bot testnet-dry-run --execute-loop --sleep-seconds 0 --evidence-out artifacts/testnet-bounded-dry-run.json
kxian-bot testnet-observe --cycles 6 --sleep-seconds 60 --execute-loop --evidence-out artifacts/testnet-bounded-observe.json
kxian-bot launch-checklist --target testnet --evidence-out artifacts/testnet-final-checklist.json
```

每一步关键输出都要确认：

- `mode=testnet`
- `exchange=binance`
- `symbol=BTCUSDT`
- `interval=4h`
- `use_testnet=true`
- `enable_testnet_autotrade=true` 只在 bounded 下单观察前开启
- `exchange-health` 的交易端点是 Binance testnet，不是生产下单端点

## 观察结果判定

`testnet-dry-run` 和 `testnet-observe` 会输出配置摘要、`profile_key`、凭证 boolean、账户同步、fill 同步、open orders、最后订单状态和 `order_lifecycle`。不要用“没有 error”作为通过标准。

可接受状态包括：

- 真实测试网订单已提交并最终 `filled`
- 真实测试网订单已提交并最终 `canceled`
- 无信号但链路健康 idle
- 被安全规则拒绝，例如无信号、无新 K 线、已有仓位、冷却中、当日限制

不可接受状态包括：

- `open_order_count > 0`
- `state=open_orders`
- 未清理的 partial/submitted 订单
- 非安全原因的 rejected
- 账户同步、fill 同步、preflight、endpoint 任一失败

## 挂单或部分成交处理

如果输出里出现 open/partial/submitted 订单：

```powershell
kxian-bot order-status --order-id <exchange_order_id>
kxian-bot cancel-order --order-id <exchange_order_id>
kxian-bot sync-fills
kxian-bot preflight
```

如果取消后仍有挂单，重复 `order-status`，确认交易所沙盒侧已经清理。清理完后再回到：

```powershell
kxian-bot testnet-dry-run --execute-loop --sleep-seconds 0
kxian-bot testnet-observe --cycles 6 --sleep-seconds 60 --execute-loop
```

## 最终完成标准

最后只运行：

```powershell
kxian-bot launch-checklist --target testnet
```

完成标准：

```text
status=pass
phase=testnet_observed_ready_for_live_review
```

到这里停止。不要执行 `launch-checklist --target live` 作为本阶段验收，不要执行 `promote-profile-to-live`，不要启动 live。

## 可选一键编排

`testnet-close-loop` 可以按固定顺序串联前置检查、非下单观察、bounded 观察和最终 checklist。默认不会进入 bounded 下单观察；必须显式加确认参数，并且 `.env` 中 `KXIAN_ENABLE_TESTNET_AUTOTRADE=true`，才会执行 `--execute-loop` 阶段。

```powershell
kxian-bot testnet-close-loop --cycles 6 --sleep-seconds 60 --evidence-dir artifacts/testnet-close-loop
kxian-bot testnet-close-loop --cycles 6 --sleep-seconds 60 --confirm-bounded-testnet-order --evidence-dir artifacts/testnet-close-loop
```

如果输出 `reason=bounded_testnet_confirmation_required`，表示非下单阶段已完成，但 bounded 阶段仍在等待人工确认。任何 credential、endpoint、profile、readiness、open orders 或 live 开关异常都必须先修复，不能用一键编排跳过。

## Dashboard 验收反馈

仪表盘测试网区域固定展示 dry-run、观察轮数、失败原因、订单闭环和验收步骤条。`下载证据` 按钮会从只读 API 导出脱敏测试网证据包，并提供 loading、成功或失败反馈。

## 离线冒烟

无真实凭证、无联网下单的基础验证：

```powershell
python -m pytest -v
kxian-bot paper-dry-run --input-file sample_data/ohlcv_smoke.csv --max-iterations 1 --sleep-seconds 0
```
